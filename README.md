# 🦙 Alpaca Image Generator

A customizable alpaca profile picture generator built with HTML, CSS, and JavaScript as part of a [DevProjects](https://www.codementor.io/projects) challenge.

## About the Project

The Alpaca Image Generator allows users to create their own personalized alpaca profile pictures by combining different visual features.

Users can customize individual features, randomize their alpaca's appearance, and download their finished creation as a PNG image.

## Features

- **Customization Panel:** Choose from eight categories of alpaca features.
- **53 Customization Options:** Mix and match hairstyles, ears, eyes, mouths, necks, legs, accessories, and backgrounds.
- **Randomize:** Generate a random combination of alpaca features.
- **PNG Download:** Download your customized alpaca as a PNG image.
- **Responsive Design:** Works on desktop and mobile screens.
- **Visual Selection Indicators:** Easily identify the currently selected category and style.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/DaveIvey/alpaca-image-generator.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. Start customizing your alpaca!
